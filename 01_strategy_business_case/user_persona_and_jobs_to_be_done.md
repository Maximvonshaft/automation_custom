# User Persona and Jobs To Be Done

## Persona

| Field | Description |
|---|---|
| User type | `<new CS agent / ops staff / warehouse operator / DSP manager / admin>` |
| Technical level | Low / Medium / High |
| Training level | None / Basic / Advanced |
| Main pressure | speed, accuracy, SLA, customer satisfaction |
| Common mistakes | wrong status, missed follow-up, unclear exception handling |

## Jobs To Be Done

Use this format:

When I am `<situation>`,
I want to `<task>`,
so that `<business outcome>`.

## Critical User Questions

Every critical page should answer:

1. Where am I?
2. What is this page for?
3. What should I do first?
4. What happens after I click?
5. What if something fails?
6. How do I know the task is complete?
