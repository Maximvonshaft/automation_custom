# Branch / PR / Issue Workflow

## Branch Naming

Use:
- `fix/<scope>-<short-description>`
- `feat/<scope>-<short-description>`
- `chore/<scope>-<short-description>`

Examples:
- `fix/admin-novice-empty-states`
- `feat/webcall-release-gate-hardening`

## Commit Message

Use conventional style:
- `fix(ui): improve ticket empty state`
- `feat(webcall): add post-release smoke checklist`
- `test(auth): cover permission denied state`

## PR Requirements

- Link issue/task.
- Fill PR template.
- Include test evidence.
- Include screenshots for UI changes.
- Include rollback plan.
- No unrelated changes.
