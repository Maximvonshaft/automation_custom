# v4.2 Pilot Rollback and Disable Runbook

## Purpose

This runbook defines how to stop or roll back an internal pilot candidate without relying on informal operator instructions.

This document does not approve external rollout. It only defines control actions that must exist before any pilot candidate is reviewed.

## Disable hierarchy

Use the least destructive control that stops new work reliably.

1. Stop issuing new signed job plans to the machine.
2. Mark the machine registration as `disabled` or `revoked` in the control process.
3. Remove the machine from the pilot machine allowlist.
4. Remove the operator from the pilot operator allowlist.
5. Delete or quarantine the local candidate package from the operator machine.
6. Preserve evidence references and support diagnostics metadata for review.

## Local operator stop procedure

Operator-facing steps:

```text
1. Stop current run after SafeBrake evidence is captured, if safe to do so.
2. Do not request new signed job plans.
3. Notify HQ support with machine_id, operator_id, job_id, and evidence_reference_id.
4. Keep local evidence bundle unchanged until HQ confirms retention or deletion handling.
```

## HQ control procedure

HQ-facing steps:

```text
1. Mark machine as disabled or revoked.
2. Stop issuing signed jobs for the affected machine_id.
3. Confirm existing jobs are short-lived and expire.
4. Confirm operator is removed from pilot allowlist if needed.
5. Record reason, timestamp, operator_id, machine_id, and affected candidate version.
6. Request evidence reference JSON and support diagnostics hash reference.
```

## Rollback record minimum fields

```text
candidate_version
source_commit
operator_id
machine_id
reason
rollback_started_at_utc
rollback_completed_at_utc
evidence_reference_id
support_diagnostics_reference
final_state
```

## Forbidden rollback shortcuts

Do not:

- ask operators to edit executable job plans;
- ship source trees as a quick patch;
- copy country pack content to local machines;
- store production credentials in local package folders;
- delete evidence before retention decision;
- bypass machine binding.

## Completion criteria

Rollback or disable is complete only when:

- no new signed job plans are issued to the disabled machine;
- operator and machine allowlists reflect the decision;
- evidence reference is collected or explicitly waived by HQ;
- local package is removed, quarantined, or marked inactive;
- support and technical owner have recorded final state.
