# v4.1 Main Fact Audit

Baseline: `main` commit `45fd4a9f5f95247432814293bced96badc80cd10`.

## Confirmed Facts

- `README.md` states v4.0 is a Controlled Runtime MVP.
- `agent/customsops_agent/action_executor.py` contains `MockActionExecutor`.
- No real Windows/ASYCUDA GUI executor exists in `main`.
- `agent/customsops_agent/signed_plan.py` validates signature, tenant, machine, expiry, mode, and
  allowed actions.
- `control_plane/app/services/job_compiler.py` exists and compiles short-lived signed-plan payloads.
- `tests/test_pack_not_in_agent.py` enforces pack isolation for `agent/`.
- `agent/customsops_agent/forbidden_actions.py` keeps Submit/Register/Payment/tax-finalizing
  actions forbidden.

## v4.1 Implication

v4.1 implementation must extend, not replace, the v4.0 control boundary. Manifest parsing and
executable job compilation stay server-side. The Windows GUI executor runs only after signed-plan
validation.
