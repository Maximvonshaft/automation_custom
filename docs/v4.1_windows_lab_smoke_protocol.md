# v4.1 Windows ASYCUDA Lab Smoke Protocol

This protocol is a controlled lab validation checklist. It is not authorization to automate
Submit/Register/Payment/tax-finalizing workflows.

## Preconditions

- PR #3 remains Draft.
- GitHub Actions quality gate has run and passed.
- Windows lab workstation has the approved Agent build.
- Operator has manually authenticated into ASYCUDA.
- The job plan is signed, short-lived, tenant-bound, machine-bound, and mode-bound.
- Runtime mode is `fillOnly` or `safeBrakeStore`.

## Controlled Run Steps

1. Start from a signed `safeBrakeStore` job.
   - Confirm `job_id`, `tenant_id`, `machine_id`, `pack_version`, and expiry.
   - Confirm no Submit/Register/Payment/tax-finalizing action is present.

2. Verify ASYCUDA foreground window.
   - Operator brings ASYCUDA to the foreground.
   - Record the exact ASYCUDA window title.
   - Abort if the window title is not ASYCUDA-confirmed.

3. Run `fillOnly` or `safeBrakeStore` in lab mode.
   - Use `fillOnly` for non-Store field population smoke.
   - Use `safeBrakeStore` only with SafeBrake currency omission active.
   - Do not run Submit/Register/Payment.

4. Capture real screenshots.
   - Capture at least one pre-run screenshot.
   - Capture field-populated screenshot.
   - Capture SafeBrake result screenshot for `safeBrakeStore`.

5. Produce `review_bundle.zip`.
   - Include `manifest_parse_report.json`.
   - Include `declaration_model.json`.
   - Include `signed_job_plan.json`.
   - Include `ledger.jsonl`.
   - Include real `screenshots/` artifacts.
   - Include watermark metadata and hashes.

## Stop Conditions

- ASYCUDA foreground window cannot be confirmed.
- Signed-plan validation fails.
- Any finalization action appears.
- SafeBrake currency omission is not active for `safeBrakeStore`.
- Evidence capture fails.
