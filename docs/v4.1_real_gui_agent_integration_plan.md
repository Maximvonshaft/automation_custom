# v4.1 Real GUI Agent Integration Plan

## Objective

Integrate signed v4 job plans with a real Windows-only ASYCUDA foreground GUI executor while
preserving the v4.0 controlled-runtime boundary.

## Non-Negotiable Boundaries

- Do not add Submit/Register/Payment automation.
- Do not add tax-finalizing automation.
- Do not move country pack content into `agent/`.
- Do not distribute this repository as an external operator package.
- Keep `control_plane/packs` server-side only.

## Work Plan

1. Signed job plan to GUI executor adapter
   - Define an adapter interface that accepts already-validated signed job plans.
   - Map allowed action grammar to Windows foreground UI operations only.
   - Keep tenant, machine, expiry, mode, and forbidden-action validation ahead of execution.

2. Evidence compatibility with v3.1.1 screenshots and ledger
   - Preserve the current evidence manifest fields and bundle layout.
   - Add adapters for v3.1.1 screenshot naming and ledger events.
   - Keep watermarking and hashes mandatory for every captured artifact.

3. SafeBrake mode preservation
   - Preserve `fillOnly` and `safeBrakeStore` as the only supported v4.1 runtime modes.
   - Keep SafeBrake mandatory blank-field behavior intact.
   - Block any finalizing action class even if a GUI control is visible.

4. Windows-only runtime boundary
   - Gate the real GUI executor behind an explicit Windows platform check.
   - Keep non-Windows execution on `MockActionExecutor` or fail closed in packaged builds.
   - Require operator-confirmed ASYCUDA foreground window before GUI actions.

5. Operator packaging without exposing country pack
   - Build an Agent artifact that excludes `control_plane/packs/**`.
   - Embed only the signing public key and generic executor code.
   - Add artifact inspection tests that fail on country-pack filenames, directories, or rule content.

## Acceptance Criteria

- Existing v4.0 validation, signing, pack isolation, and evidence tests continue to pass.
- New GUI adapter tests use mocks/stubs for Windows UI calls unless run on a controlled Windows lab
  machine.
- Real GUI execution remains limited to signed `fillOnly` and `safeBrakeStore` job plans.
- Evidence bundles remain compatible with v3.1.1 screenshot and ledger review workflows.
