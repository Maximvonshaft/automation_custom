## Remaining Limitations

- Real Windows GUI operations are represented by a Windows-only adapter scaffold and require Windows
  lab integration before production use.
- `Simplified` parsing is classified but remains P1.
- Manifest intake currently uses structured workbook payloads in tests/API; production `.xlsx`
  binary parsing should be wired behind the same service boundary.
