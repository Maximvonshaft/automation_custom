## Functional scope

Allowed:

- local readiness status;
- superficial Excel manifest precheck;
- HQ-issued signed job execution;
- evidence bundle creation;
- reference-only evidence metadata generation;
- support diagnostics hash reference.

Not allowed:

- source tree distribution;
- country pack exposure;
- local executable-plan compilation from Excel;
- final customs submission workflow automation;
- production credential storage;
- raw sensitive evidence committed to repository.

## Required operator instructions

1. Use only the assigned machine.
2. Use only short-lived signed job plans issued by HQ.
3. Do not edit executable steps.
4. Do not copy the package to unapproved machines.
5. Send only evidence references unless HQ separately requests redacted evidence artifacts.
6. Report any ASYCUDA foreground, signature, expiry, or evidence generation failure.
