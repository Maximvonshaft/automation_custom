# v4.3 Broker Excel Template Pilot

## Purpose

This pilot connects the broker-provided Excel template to the Albania ASYCUDA Line Transaction v3.1.1 SafeBrake coordinate pack imported in PR #25.

The objective is to compile broker Excel rows into control-plane job plans for supervised ASYCUDA foreground execution.

## Boundary

The Excel parser and batch compiler are control-plane components.

They must not be copied into the local operator agent package as local Excel-to-executable-plan compilation capability.

The Local Operator remains signed-job-only.

Forbidden actions remain forbidden:

```text
submit
register
payment
tax_finalize
```

## Input template

Expected workbook sheet:

```text
Combine合并订单
```

The template has two header rows and consolidated declaration groups. A group header row is identified by populated columns such as:

```text
Frequency / Count
Consolidated Value
HS Code / Tariff Code
Total Weight (kg)
```

Rows between one group header and the next group header are treated as item rows in the same consolidated declaration group.

## Important mapping

```text
Excel group                  Compiler declaration
-------------------------------------------------
HS Code / Tariff Code        customs_tariff_1
constant 000                 customs_tariff_2
sum(Sasia)                   statistical_quantity
Description of Goods         goods_description
Origjina prej nga vije       origjina
Total Weight (kg)            gross_weight / net_weight
Consolidated Value           invoice_value
first Kodi                   document_reference
all Kodi values              document_reference_all metadata
currency                     intentionally blank
```

Do not use Frequency / Count as statistical quantity. The parser sums `Sasia` across item rows.

## SafeBrake

Currency / Monedha is intentionally blank.

This is a safety fuse intended to prevent successful Line Store while allowing field fill and SafeBrake validation testing.

## Runtime defaults

The broker Excel template does not currently provide all ASYCUDA runtime values. The pilot console therefore requires:

```text
authorization_reference
truck_registration_plate_number
```

Defaults are also supplied for:

```text
customs_office = AL111000
means_transport_code_1 = 50
means_transport_country_from = RS
means_transport_country_to = AL
customs_tariff_2 = 000
```

## CLI usage

```powershell
python -m control_plane.app.services.albania_batch_compiler `
  --excel .\lab\broker_10row_test.xlsx `
  --out-dir .\outputs\broker_10row_batch `
  --authorization-reference AL2025 `
  --truck-registration-plate-number L92008015T `
  --include-store-safebrake
```

Output:

```text
outputs/broker_10row_batch/batch_manifest.json
outputs/broker_10row_batch/plans/*.json
```

## Visual pilot console

```powershell
.\scripts\albania_template_console.ps1
```

The console compiles batch plans only. It does not execute ASYCUDA directly.
