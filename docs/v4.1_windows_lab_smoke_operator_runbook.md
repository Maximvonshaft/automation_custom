# v4.1 Windows ASYCUDA Lab Smoke Operator Runbook

## Purpose

Run one signed `fillOnly` or `safeBrakeStore` job against an operator-confirmed ASYCUDA foreground
window and produce a v3.1.1-compatible `review_bundle.zip` plus a sanitized `smoke_result.md`.

This runbook is for controlled Windows lab evidence only. It does not approve external deployment.

## Boundaries

- Do not run Submit/Register/Payment/tax-finalizing automation.
- Do not place country pack content under `agent/`.
- Do not compile executable job plans locally from Excel.
- Do not commit sensitive screenshots, real customer Excel, real AWB rows, broker authorization
  values, production credentials, or country pack secrets.
- Runtime mode must be `fillOnly` or `safeBrakeStore`.
- SafeBrake remains the default validation mode.

## Preconditions

- Windows lab workstation.
- ASYCUDA is already opened and manually authenticated by the operator.
- ASYCUDA foreground window title contains `ASYCUDA`.
- Signed job plan is short-lived and bound to the lab tenant and machine.
- `CUSTOMSOPS_TENANT_ID` and `CUSTOMSOPS_MACHINE_ID` are set.
- Either `CUSTOMSOPS_SIGNING_PUBLIC_KEY_PEM` is set or a public key PEM file is available.

## One-Command Run

```powershell
.\scripts\windows_lab_smoke_runner.ps1 `
  -SignedJobPlan ".\lab\signed_job_plan.safeBrakeStore.json" `
  -PublicKeyPem ".\lab\public_key.pem" `
  -AsycudaWindowTitle "ASYCUDAWorld" `
  -EvidenceRoot ".\outputs\windows_lab_smoke"
```

Optional sanitized metadata inputs:

```powershell
.\scripts\windows_lab_smoke_runner.ps1 `
  -SignedJobPlan ".\lab\signed_job_plan.safeBrakeStore.json" `
  -PublicKeyPem ".\lab\public_key.pem" `
  -AsycudaWindowTitle "ASYCUDAWorld" `
  -EvidenceRoot ".\outputs\windows_lab_smoke" `
  -ManifestParseReport ".\lab\manifest_parse_report.sanitized.json" `
  -DeclarationModel ".\lab\declaration_model.sanitized.json" `
  -KnownIssues "No known issues in lab run."
```

## Outputs

The runner writes outputs under `-EvidenceRoot`:

- `review_bundle.zip`
- `smoke_result.md`
- `manifest_parse_report.json`
- `declaration_model.json`
- `signed_job_plan.json`
- `ledger.jsonl`
- `screenshots/`
- `watermark_metadata.json`

Only commit or attach sanitized references:

- `smoke_result.md` after redaction review;
- `review_bundle.zip` hash;
- screenshot hash summary;
- known issues;
- boundary confirmation.

Do not commit the actual `review_bundle.zip` or screenshots if they contain sensitive ASYCUDA or
customer data.

## Failure Behavior

The runner fails closed when:

- not running on Windows;
- `CUSTOMSOPS_TENANT_ID` is missing;
- `CUSTOMSOPS_MACHINE_ID` is missing;
- no public key is provided;
- ASYCUDA foreground title does not contain `ASYCUDA`;
- signed job validation fails;
- the job mode is not `fillOnly` or `safeBrakeStore`;
- the signed job contains Submit/Register/Payment/tax-finalizing actions.
