# PR27 Broker Fill Hardening

## Source evidence

PR27 is driven by the 2026-05-30 polling-key forensic bundle captured on the
ASYCUDA machine after the first ALI2025 SafeBrake run.

Evidence fixed by the probe:

- F12 and Ctrl+Alt+F12 hotkey registration failed in the ASYCUDA/remote desktop
  environment, so the successful probe used polling rather than RegisterHotKey.
- The ALI2025 signed run completed and produced reference-only evidence.
- The first ALI2025 screenshot showed field/state contamination risk, including
  values appearing outside their intended fields.
- Manual coordinate capture showed material x-axis drift from the imported
  v3.1.1 coordinate pack for several high-risk fields.

## Engineering change

The broker pilot now uses clear-before-paste semantics:

- `click_clear_paste`: click target field, Ctrl+A, paste value.
- `clear_paste`: Ctrl+A, paste value for already-focused fields.

This prevents value concatenation when ASYCUDA pages are reused or contain
defaults. The runbook still requires a fresh blank Line Transaction page for
each pilot job.
