# Incident Response Playbook

## Severity

| SEV | Meaning | Example | Response |
|---|---|---|---|
| SEV1 | Major outage/security/data loss | critical workflow unavailable | immediate response |
| SEV2 | Major degradation | high failure rate | urgent response |
| SEV3 | Moderate issue | workaround exists | normal response |
| SEV4 | Minor issue | cosmetic/minor defect | backlog/fix |

## Response Steps

1. Declare incident.
2. Assign incident commander.
3. Stabilize: rollback/disable flag/mitigate.
4. Communicate status.
5. Investigate root cause.
6. Verify recovery.
7. Complete postmortem.
8. Track corrective actions.
