# Operator SOP

## Operator can

- start assigned job;
- confirm ASYCUDA is open and logged in;
- keep geometry locked;
- upload/send evidence bundle;
- report failure with bundle.

## Operator cannot

- access Country Pack;
- edit job plan;
- run expired jobs;
- execute Submit/Register;
- copy automation to other machines.

## SafeBrake workflow

1. Open ASYCUDA normally.
2. Run assigned SafeBrake job.
3. Confirm expected ASYCUDA validation block appears.
4. Submit evidence bundle to HQ.
