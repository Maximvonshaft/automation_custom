# Design Review Checklist

- [ ] Page purpose is clear within 5 seconds.
- [ ] Main action is visually obvious.
- [ ] Copy uses business language.
- [ ] Empty state gives next action.
- [ ] Error state gives recovery path.
- [ ] Loading state prevents duplicate action where needed.
- [ ] Dangerous action explains consequence.
- [ ] Advanced/admin/debug tools are not exposed to normal users.
- [ ] No dead button, fake route, or misleading mock.
- [ ] Accessibility basics checked.
- [ ] Mobile/responsive behavior checked if applicable.
