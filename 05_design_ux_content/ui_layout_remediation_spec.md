# UI Layout Remediation Spec

## Page Template

| Section | Requirement |
|---|---|
| Page title | Business purpose, not database object |
| Subtitle | Who/what this page helps with |
| Primary CTA | One clear main action |
| Filters/search | Only when useful to the main task |
| Data table/list | Clear columns, human labels |
| Empty state | Explanation + next action |
| Error state | Human-readable cause + recovery |
| Advanced tools | Hidden/collapsed/role-gated |
