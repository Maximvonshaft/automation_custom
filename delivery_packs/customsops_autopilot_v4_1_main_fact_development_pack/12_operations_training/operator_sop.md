# Operator SOP — Target UX

## Operator should do

1. Open Agent.
2. Drag approved Excel manifest template.
3. Review parse summary.
4. Confirm ASYCUDA is open and logged in.
5. Run `SafeBrake` by default.
6. Send/review generated evidence bundle.

## Operator should not do

- Inspect or edit field coordinates.
- Receive country pack files.
- Run Submit/Register/Payment automation.
- Use unapproved Excel templates.
- Move ASYCUDA window during execution.
