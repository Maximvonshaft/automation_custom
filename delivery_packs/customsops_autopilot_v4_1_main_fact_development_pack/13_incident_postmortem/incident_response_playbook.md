# Incident Response Playbook

## Severity examples

- SEV1: Any Submit/Register/Payment/tax-finalizing action executed unexpectedly.
- SEV2: Agent distributed with country pack content.
- SEV2: Job plan accepted without valid signature.
- SEV3: Template parser misclassified workbook.
- SEV3: Evidence bundle missing required hashes.

## Immediate actions

1. Revoke tenant/machine/job issuance.
2. Preserve logs and evidence bundles.
3. Disable affected pack version.
4. Perform root-cause review against this construction pack.
