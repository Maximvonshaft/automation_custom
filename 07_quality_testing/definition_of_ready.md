# Definition of Ready

A Codex implementation task is ready only when:

- Scope and non-scope are accepted.
- Target repository and branch are known.
- Current v3.1.1 package is treated as internal reference only.
- No external distribution of source ZIP is allowed.
- The allowed v4.0 modes are confirmed: `fillOnly`, `safeBrakeStore`.
- Submit/Register/Payment actions are blocked.
- Signing algorithm is confirmed: Ed25519.
- Evidence bundle requirements are accepted.
