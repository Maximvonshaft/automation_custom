# Definition of Done

v4.0 is done when:

1. Local Agent executes only signed job plans.
2. Control Plane can compile and sign SafeBrake jobs.
3. Agent rejects invalid, expired, wrong-machine, wrong-tenant, and forbidden-action jobs.
4. Agent build artifact does not contain full Country Pack.
5. Evidence bundles are generated and watermarked.
6. Kill switch works.
7. Tests pass.
8. Release and rollback docs are complete.
9. Final engineer report is complete.
