# Manual QA Checklist

## General

- [ ] Page loads successfully.
- [ ] No console errors in normal flow.
- [ ] Primary CTA is clear.
- [ ] Empty state is actionable.
- [ ] Error state is actionable.
- [ ] Loading state is visible.
- [ ] Disabled state explains why.
- [ ] Dangerous actions require confirmation.
- [ ] No dead buttons or fake entries.
- [ ] Permission-denied state is clear.

## Novice User Check

- [ ] A new user can identify page purpose.
- [ ] A new user knows the next step.
- [ ] Technical terms are avoided or explained.
- [ ] Business workflow order is clear.
- [ ] User knows when task is complete.
